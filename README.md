# ResearchTree

*Every branch is an experiment. Every PR is its lab note.*

ResearchTree turns your Git history into a living map of your research.
Each experiment lives on its own branch with a small, focused change,
and its pull request serves as the lab note: hypothesis, metrics, and
conclusions. ResearchTree reads these PRs and renders them as a tree
that grows from your initial implementation, so you can see which ideas
branched from where, which ones were adopted, and which were ruled out.
Click any node to view its results or edit the PR directly.
