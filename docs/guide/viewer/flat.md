# 평면 보기

툴바에서 **평면 보기**를 누르면 섬을 위에서 내려다보는 평면 화면으로 바뀌어요. 버튼을 다시 누르면(**입체 보기**) 원래 3D 섬으로 돌아옵니다. 노드를 선택한 상태로 보기를 전환해도 선택이 그대로 유지되며, 마지막으로 본 화면은 다음 접속 때도 기억돼요.

![평면 보기](/images/readme/flat-tree.png)

## 눌러 내리기 전환

평면 보기는 별개 화면이 아니라 **같은 3D 장면**이에요. 화면을 새로 불러오지 않고 그 자리에서 부드럽게 연출됩니다.

- **입체 → 평면**: 카메라가 수직 시점으로 회전하면서 식물이 바닥으로 납작하게 눌려요. 땅과 물, 나루터와 나룻배, 주변 장식은 감춰지고 흙길, 텃밭과 납작해진 식물, 버전 돌, 라벨 칩만 점무늬 배경 위에 남습니다. 섬 사이 바다를 건너던 길은 점선 길 타일로 바뀌어 가지가 끊기지 않고 자연스럽게 이어져요.
- **평면 → 입체**: 납작했던 섬이 다시 위로 솟아오르며 원래 등각 시점으로 돌아옵니다.

![눌러 내리기 효과](/images/readme/press-down.png)

## 평면 읽는 법

- 기본 배치는 [3D 섬](/viewer/island)과 같아요. 루트(`research`)에서 오른쪽으로 뻗어나가며, `research`와 `experiment/*` 외의 브랜치는 화면에 나타나지 않습니다.
- 가로축은 [시간](/viewer/seasons) 순서를 따라요. 실험은 시작 날짜, 버전은 태그 날짜 위치에 놓이고, 자식 노드는 부모 노드보다 항상 오른쪽에 배치됩니다. 해가 바뀌는 경계에는 연도 칩이 보이며, 왼쪽 위 레포 정보 카드 아래에는 현재 화면 중앙의 연도와 계절이 표시돼요.

| 요소 | 뜻 |
|---|---|
| 흙길 | 부모에서 자식으로 뻗는 가지. 가지마다 색이 섞여 있습니다 |
| 텃밭과 눌린 식물 | 실험 하나. 식물 모양은 3D 섬과 동일하게 실험 상태를 나타냅니다 |
| 돌 기념탑(위에서 본 모습) | research 버전 |
| 합류 흙길 | 버전 합류선. 한 버전에 합쳐진 나머지 실험을 이어줍니다 |
| 점선 길 | 섬 사이 바다를 건너는 길. 3D 섬의 나루터와 나룻배 자리입니다 |
| 느낌표 배지 | YAML 오류, 필수 필드 누락, 고아 노드 등의 경고 |

노드 라벨에는 브랜치 이름이 적히고, 그 아래에 [라벨 메트릭](/viewer/navigation#라벨-메트릭) 값과 상태가 작게 표시돼요.

## 조작

드래그로 화면을 이동하고 마우스 휠로 확대·축소해요. 평면 보기에서는 회전할 수 없습니다. 노드를 누르면 상세 패널이 열리며, 키보드 조작 방식은 3D 화면과 같아요([탐색과 도구](/viewer/navigation)).
