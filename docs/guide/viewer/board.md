# 칸반 보기

섬이 연구가 어떻게 자랐는지를 보여준다면, 칸반 보기는 **개발이 지금 어디까지 왔는지**를 보여줘요. 같은 실험을 개발자들이 익숙한 작업 보드로 세워 놓은 화면입니다.

툴바의 **칸반 보기** 버튼을 누르면 바뀌고, **섬으로 돌아가기**를 누르면 원래 화면으로 돌아와요. 마지막으로 본 화면은 다음 접속 때도 기억됩니다.

## 다섯 개의 열

열은 PR이 실제로 거치는 단계예요. GitHub에 있는 값 그대로라서 따로 관리할 것이 없어요.

| 열 | 여기 들어오는 PR |
|---|---|
| **초안** | draft로 열어 둔 PR. 아직 남에게 보여줄 준비가 안 된 실험이에요 |
| **작업 중** | 열려 있고 리뷰 요청이 없는 PR |
| **리뷰 중** | 리뷰어나 팀에게 리뷰를 요청한 PR |
| **채택** | 머지된 PR |
| **기각** | 머지 없이 닫힌 PR |

카드는 마지막으로 움직인 순서대로 놓여요. 맨 위가 가장 최근입니다.

## 카드 읽는 법

카드 한 장이 실험 하나예요. 실험 이름과 PR 번호, 제목, 그리고 상태와 라벨 메트릭, 작성자가 함께 보입니다. 왼쪽의 작은 점은 섬에서 쓰는 것과 같은 표시라, 진행 중·채택·기각을 색으로 구분할 수 있어요.

카드를 누르면 섬에서와 똑같은 상세 패널이 열려요. 가설과 변경점, 메트릭, 커밋, 스펙까지 그대로 볼 수 있습니다.

레포 카드의 **진행 중 · 채택 · 기각** 칩을 끄면, 칸반에서도 해당 실험 카드가 흐려져요. 열은 그대로 두고 카드만 흐려지기 때문에, 무엇이 빠졌는지 눈에 보입니다.

## 언제 쓰면 좋을까

- **오늘 뭘 할지 정할 때**: 리뷰 중 열이 비어 있는지, 작업 중이 너무 많지 않은지 한눈에 보여요.
- **실험 진행 상황을 공유할 때**: 연구 이야기 없이 진행 상황만 보여주기 좋아요.
- **정리할 때**: 오래 멈춘 초안이나 작업 중 카드가 그대로 드러나요.

::: tip 섬과 칸반은 같은 데이터예요
보기를 바꿔도 선택한 실험과 설정은 그대로 유지돼요. 칸반에서 고른 실험은 섬으로 돌아가도 선택된 채로 있습니다.
:::
