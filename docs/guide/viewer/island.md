# 3D 연구의 섬

레포를 열면 기본 화면으로 **연구의 섬**이 나타납니다. 파스텔톤 복셀 섬을 등각(아이소메트릭) 시점으로 내려다보는 화면이에요. 루트 `v1`을 비롯한 research 버전마다 섬이 하나씩 생기고, 각 실험은 뻗어 나온 버전의 섬에 자리 잡습니다. 섬 사이는 넓은 바다로 떨어져 있어서 버전 경계가 한눈에 들어와요.

![3D 연구의 섬](/images/readme/ko/island.png)

## 섬 읽는 법

| 섬의 요소 | 뜻 |
|---|---|
| **큰 고목** | 루트인 `research` 브랜치이자 첫 버전 `v1` |
| **흙길** | 부모에서 자식으로 뻗는 가지예요. 가지마다 색이 섞여 있고, 루트나 버전에서 새로 뻗은 가지가 새 색을 받아 자손에게 물려줍니다 |
| **텃밭의 식물** | 실험 하나예요. 길 끝 텃밭에 심겨 있습니다 |
| **돌 기념탑과 깃발** | research 버전(`v2`, `v3` …)이에요. 채택되어 research에 머지된 실험 뒤에 세워지며, 이 버전에서 다시 길이 뻗어나갑니다 |
| **합류 흙길** | 한 버전에 여러 실험이 합쳐졌을 때 나머지 실험에서 버전으로 이어지는 길이에요 |
| **나루터와 나룻배** | 버전 섬 사이는 넓은 바다예요. 다음 버전으로 가는 길은 섬 가장자리에서 기둥 위 나무 나루터로 끝나고, 섬 사이 물 위에는 돛과 가지 색 깃발을 단 작은 나룻배가 매여 흔들립니다 |
| 꽃, 풀, 돌, 덤불, 구름 | 장식 요소예요. 섬 모양과 장식은 레포 이름에 따라 정해져서 다시 열어도 늘 같습니다 |

### 식물 = 상태

| 식물 | 상태 |
|---|---|
| 열매와 울타리가 있는 다 자란 나무 | **채택** (merged 또는 `status: adopted`) |
| 살랑이는 묘목 | **진행 중** (open) |
| 잿빛 그루터기와 떨어진 잎 | **기각** (closed 또는 `status: rejected`) |
| 새싹 둔덕 | **초안** (Draft PR) |

나무 수관은 가지 색을 띠고, 마지막으로 작업한 계절은 꽃·반딧불·낙엽·눈 같은 효과로 나타나요([시간축과 계절](/viewer/seasons)).

## 라벨 칩

노드 위에는 흰색 라벨 칩이 떠 있어요. 칩에는 접두사를 뺀 브랜치 이름과 [라벨 메트릭](/viewer/navigation#라벨-메트릭) 값, 상태만 표시됩니다. YAML 오류가 있거나 고아 노드인 경우 경고 배지가 함께 붙어요.

## 조작

| 동작 | 조작 |
|---|---|
| 이동 | 드래그 |
| 회전 | 오른쪽 드래그 |
| 확대/축소 | 휠 |
| 노드 선택 | 식물이나 라벨 칩 클릭 → 카메라가 이동하며 [상세 패널](/viewer/panels) 열림 |
| 노드 이동 | 방향키 ([키보드](/viewer/navigation#키보드)) |
| 선택 해제 | Esc |

선택한 노드에는 가지 색 고리가 깜빡여요. [상태 레이어](/viewer/navigation#상태-레이어)로 숨긴 실험은 반투명하게 흐려집니다.

## 자라나는 연출

처음 화면을 열면 세대 순서대로 길이 뻗어나가며 식물이 자라나요. 운영체제에서 "동작 줄이기(reduced motion)" 설정을 켜 두면 이 애니메이션을 건너뜁니다.

::: tip WebGL이 없을 때
뷰어는 WebGL로 화면을 그려요. 브라우저에서 WebGL을 쓸 수 없으면 트리를 그릴 수 없다는 안내가 나타납니다. [평면 보기](/viewer/flat) 역시 같은 3D 장면을 쓰므로 대체해서 볼 수 없어요. 브라우저 설정에서 하드웨어 가속이 켜져 있는지 확인해 주세요.
:::
