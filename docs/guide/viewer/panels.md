# 상세 패널과 버전 패널

노드를 누르면 오른쪽에 패널이 열려요. 화면이 좁을 때는 아래에서 위로 올라옵니다. 패널 오른쪽 위의 ✕ 버튼이나 Esc 키로 닫을 수 있어요.

## 실험 상세 패널

패널 머리에서는 다음 정보를 확인할 수 있어요.

- `Experiment · #PR번호`와 PR 제목
- **경로**: 루트부터 이 실험까지 거쳐 온 노드(버전 포함). 누르면 해당 노드로 이동합니다
- 상태 배지, 초안 여부, 전체 브랜치 이름
- 작성자, PR을 연 날짜, 머지/종료일

경고가 있으면 **내용** 탭 맨 위에 경고 내용이 표시돼요.

### 탭

| 탭 | 내용 |
|---|---|
| **내용** | `hypothesis`(확인하려는 가설), `change`(변경 사항), YAML 블록 아래의 PR 본문(마크다운 렌더링), `tags`, 검증하는 주장(`claims`). **수정** 버튼으로 가설, 변경, 상태, 태그, W&B 링크와 YAML 아래 본문 전체(결론, 메모 등)를 바로 고칠 수 있어요 |
| **협업** | PR의 댓글과 코드 리뷰 댓글. 아래 입력칸에서 마크다운으로 댓글을 남길 수 있어요 |
| **메트릭** | `metrics` 표. 현재 실험과 부모 노드, 증감(Δ)을 나란히 보여줍니다. 부모가 버전이면 그 버전이 이어진 줄기 끝 실험의 메트릭이 기준이 돼요 |
| **커밋** | 브랜치의 커밋 목록. 누르면 GitHub에서 커밋을 엽니다 |
| **변경사항** | PR의 Files changed. 파일마다 추가·삭제 줄 수가 나오고, 누르면 diff를 펼쳐 봐요 (파일당 앞 400줄) |
| **스펙** | 이 브랜치가 갈라진 지점과 비교해 스펙 문서에서 추가·수정·삭제한 섹션. 누르면 그 섹션의 줄 단위 변경이 펼쳐져요. 기각된 실험이면 제안으로만 남았다고 알려줘요([의도와 스펙 문서](/rules/spec)) |

메트릭 증감(Δ) 색상은 키 이름을 보고 자동으로 판단해요. `loss`, `wer`, `cer`, `error`, `latency`, `ppl` 등은 낮을수록, `acc`, `score`, `bleu`, `f1`, `mos` 등은 높을수록 좋은 것으로 봅니다. 파악할 수 없는 키는 별도 색상 없이 표시돼요.

### 버튼과 링크

- **GitHub에서 열기**: PR 페이지를 새 탭(VS Code에서는 기본 웹 브라우저)으로 엽니다.
- **학습 기록**: YAML에 `wandb` 필드가 있을 때 표시돼요.
- **체크아웃**, **부모 대비 diff**: [VS Code 확장](/guide/vscode#확장-전용-기능)에서만 쓸 수 있습니다.
- **파생 실험**: 이 실험에서 뻗어 나간 자식 실험(및 이 실험이 만든 버전)을 칩으로 보여줍니다. 누르면 해당 노드로 바로 이동해요.

::: tip 수정은 안전하게
**수정**으로 저장하면 YAML 블록에서는 고친 필드(`hypothesis`, `change`, `status`, `tags`, `wandb`)만 바뀌고, `metrics`나 `parent` 같은 다른 필드와 주석, 필드 순서는 그대로 남아요. 상태를 **자동**으로 두면 `status` 필드를 지우고 PR 상태(머지·close)를 따라요. 트리를 불러온 뒤 GitHub에서 본문이 바뀌었다면 덮어쓰지 않고 새로고침하라고 알려 줘요. 학습 코드에서는 [`rt.log()`](/guide/tracking)로 메트릭을 기록할 수 있습니다.
:::
## 버전 패널

돌 기념탑(입체·평면 모두)을 누르면 버전 패널이 열려요. 첫 버전 `v1`은 `research` 고목을 누르면 볼 수 있습니다. 버전 패널에는 **개요**와 **스펙** 두 탭이 있어요.

![버전 패널](/images/readme/ko/version-panel.png)

| 항목 | 내용 |
|---|---|
| 머리 | 버전 이름(`research v2`), 태그 커밋 SHA, 태그 날짜 |
| **합쳐진 실험** | 이 버전을 만든 채택 실험들 |
| **이 버전의 메트릭** | 버전이 이어진 줄기 끝 실험의 메트릭 |
| **이 버전에서 시작한 실험** | `parent: research@v2`이거나 이 버전 시점에 research에서 시작한 실험 |
| **다음 버전** | 이어지는 버전 |
| **라벨 메트릭** | 이 섬의 노드 라벨에 띄울 메트릭. 이 섬의 실험들이 기록한 키가 많이 쓰인 순서로 나오고, **표시 안 함**으로 끌 수 있습니다([라벨 메트릭](/viewer/navigation#라벨-메트릭)) |

위 표는 **개요** 탭이에요. **스펙** 탭은 그 버전 시점의 스펙 문서를 **전체**, **요약**, **이 버전의 변경** 세 가지로 보여주고, 섹션마다 이력을 펼쳐 볼 수 있어요. 가장 최근 버전의 스펙 탭이 지금의 최종 스펙이에요([의도와 스펙 문서](/rules/spec#뷰어에서-보기)).

규칙은 [research 버전 태그](/rules/versions) 문서를 참고해 주세요.
