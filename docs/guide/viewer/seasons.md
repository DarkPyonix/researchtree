# 시간축과 계절

트리는 시간의 흐름을 따라 자라나요. 노드 위치와 섬 풍경을 보면 **언제** 진행한 실험인지 한눈에 알 수 있습니다.

::: info 새 기능
시간축과 계절 표현은 최근에 추가된 기능이에요. 세부 연출은 앞으로 달라질 수 있습니다.
:::

## 시간축

- 가로축은 실제 날짜 순서를 따릅니다. 실험은 **시작한 날**, 버전은 **태그 커밋 날짜** 위치에 놓여요.
- 노드는 기본적으로 날짜 위치에 놓입니다. 다만 자식 노드는 부모보다 항상 오른쪽에 배치되고 가지 사이 간격도 필요해서, 짧은 기간에 실험이 몰리면 실제 날짜보다 오른쪽으로 밀릴 수 있어요. 새 버전의 섬은 넓은 바다를 사이에 두고 시작합니다.
- 연도 눈금과 계절은 노드가 실제로 놓인 자리에 맞춰 함께 늘어납니다. 그래서 노드가 밀려도 눈금이 가리키는 날짜와 노드의 날짜가 어긋나지 않아요.
- 모든 노드의 날짜가 거의 비슷하면(4일 이내) 시간축 대신 세대 순서대로 배치합니다.

### 연도 눈금과 현재 연도

- 해가 바뀌는 지점(1월 1일)마다 **연도 칩**이 놓여요. 3D 섬에서는 그 자리에 돌 띠도 깔립니다. 땅이 사라지는 평면 보기에서는 이 연도 칩으로 해 경계를 알아볼 수 있어요.
- 왼쪽 위 레포 정보 카드 바로 아래에 현재 화면 가운데 지점의 **연도**(크게)와 **계절**(작게)이 표시됩니다. 입체와 평면 모두에서 볼 수 있고, 가로로 이동하면 해와 계절이 지나가는 모습을 확인할 수 있어요.

## 계절

날짜는 북반구 기준 계절로 나눕니다.

| 계절 | 기간 |
|---|---|
| 봄 | 3월 ~ 5월 |
| 여름 | 6월 ~ 8월 |
| 가을 | 9월 ~ 11월 |
| 겨울 | 12월 ~ 2월 |

- **3D 섬의 땅**: 풀빛과 꽃·덤불 장식이 시간축 위치의 계절을 따릅니다. 봄에는 꽃잎, 여름에는 짙은 풀, 가을에는 황금빛 들판, 겨울에는 눈이 덮여요. research 버전마다 섬이 따로 있고, 섬 사이 바다는 나루터에 매인 나룻배로 건넙니다.
- **실험 나무**: 수관은 가지(브랜치) 고유 색을 유지하고, 그 실험을 **마지막으로 작업한 시점**의 계절이 효과로 나타나요. 어느 가지를 어느 계절까지 손봤는지가 섬 풍경에 자연스럽게 드러납니다.

| 계절 | 실험 나무의 효과 |
|---|---|
| 봄 | 나무에 벚꽃이 피고 꽃잎이 흩날립니다 |
| 여름 | 나무 주위에 반딧불이 은은하게 빛나며 떠다닙니다 |
| 가을 | 잎이 떨어지고 텃밭에 낙엽이 쌓여요 |
| 겨울 | 눈이 내리고 수관과 그루터기, 새싹 위에 눈이 얹힙니다 |

떨어지거나 떠다니는 효과는 "동작 줄이기(reduced motion)"를 켜거나 평면 보기일 때 멈춥니다. 피어 있는 꽃, 낙엽, 눈 모자는 그대로 남아요.

## 날짜는 어디서 오나

| 값 | 우선순위 |
|---|---|
| 시작 시점 | ① PR 본문 YAML `started` → ② 브랜치의 첫 커밋 → ③ PR을 연 시각 |
| 마지막 작업 시점 | ① YAML `ended` → ② 브랜치의 마지막 커밋 → ③ PR 머지 / close / 수정 시각 |

마지막 작업 시점이 시작보다 앞서면 시작 시점에 맞춥니다. 실험을 PR보다 한참 먼저 시작했거나, 과거 기록을 옮겨 올 때는 YAML에 날짜를 적어 주세요.

```yaml
hypothesis: warmup을 2k step 두면 초반 발산 없이 빠르게 수렴한다
started: 2026-03-02
ended: 2026-03-20
```

`started`/`ended`는 `YYYY-MM-DD` 또는 전체 ISO 시각을 받습니다. 그 밖의 형식은 무시돼요.
