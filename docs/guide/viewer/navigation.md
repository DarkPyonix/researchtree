# 탐색과 도구

## 화면 구성

| 위치 | 요소 |
|---|---|
| 왼쪽 위 | **레포 정보 카드**: 레포 이름, 실험 수, 버전 수와 최대 세대, 상태 레이어. 카드 바로 아래에 화면 중앙 지점의 연도(크게)와 계절(작게) |
| 오른쪽 위 | **툴바**: 새로고침, 보기 전환, 설정, 전체 보기, 계정 메뉴 |
| 오른쪽 | 상세 패널 / 버전 패널 |
| 아래 가운데 | **세대 이동** 바 |
| 왼쪽 아래 | 조작 힌트 |

## 툴바

| 버튼 | 동작 |
|---|---|
| **새로고침** | GitHub에서 PR과 태그를 다시 읽어와 트리를 새로고침해요. 선택한 노드는 유지됩니다 |
| **평면 보기 → 트리 보기 → 입체 보기 → 섬 보기** | 누를 때마다 다음 보기로 바뀌어요: 평면, 버전이 아래에서 위로 자라는 트리 방향의 평면, 같은 방향의 입체, 처음 화면([평면 보기](/viewer/flat#평면-보기)) |
| **설정** | [언어와 브랜치 설정](#설정) 창 열기 |
| **전체 보기** | 트리 전체가 화면에 들어오도록 구도를 맞춥니다 |
| **@계정** | 계정 메뉴. 마우스를 올리면 열리고(터치 화면에서는 눌러서 여닫기), 상세 패널보다 위에 나타납니다. 메뉴 항목: 이 레포 GitHub에서 열기, 다른 레포 열기, [사용 가이드](https://darkpyonix.github.io/researchtree/guide/), [ResearchTree 저장소](https://github.com/DarkPyonix/researchtree), 로그아웃 |

## 상태 레이어

레포 정보 카드의 **진행 중 / 채택 / 기각** 칩으로 원하는 상태의 실험만 골라볼 수 있어요. 칩 옆 숫자는 해당 상태인 실험 수입니다. 칩을 눌러 끄면 해당 실험들이 흐려지고(3D에서는 반투명 처리), 다시 누르면 원래대로 돌아옵니다.

## 라벨 메트릭

라벨 메트릭은 **섬(research 버전)마다** 따로 골라요. 버전이 바뀌면 주로 보는 지표도 달라지기 때문입니다. 선택한 메트릭 값은 해당 섬의 노드 라벨 아래에 작게 표시돼요.

1. 섬의 버전 기념탑을 누릅니다. 첫 섬(`v1`)은 `research` 고목을 누르면 돼요. [버전 패널](/viewer/panels#버전-패널)이 열립니다.
2. 패널의 **라벨 메트릭** 목록에서 원하는 메트릭 키를 골라주세요.

- 목록에는 해당 섬의 실험들이 기록한 `metrics` 키가 사용 빈도순으로 나타납니다.
- 기본으로는 가장 많이 쓰인 키가 선택되어 있어요. **표시 안 함**을 고르면 끌 수 있습니다.
- 선택한 값은 레포별로 저장되어 다음에도 유지돼요.

## 세대 이동

화면 아래 가운데의 **세대** 바를 이용하면 루트 기준 깊이(세대) 단위로 이동할 수 있어요. `01`, `02` … 버튼을 누르면 해당 세대의 노드들이 화면에 맞춰지고, `‹` `›`로 이전이나 다음 세대로 넘어갑니다. **전체 보기**를 누르면 세대 선택이 풀려요.

- 바 너비는 화면의 약 1/3입니다. 한 번에 보이지 않는 세대는 마우스 휠이나 `‹` `›`로 가로 스크롤할 수 있고, 양쪽 가장자리는 은은하게 흐려집니다.
- 선택한 세대는 바 한가운데로 옵니다.
- 오른쪽 카운터는 `12 / 18`처럼 선택한 세대와 전체 세대 수를 보여줘요. 선택이 없으면 `전체 18`로 표시됩니다.

## 키보드

| 키 | 동작 |
|---|---|
| `→` | 첫 번째 자식으로 이동 (선택 노드가 없으면 루트의 첫 자식) |
| `←` | 부모로 이동 |
| `↑` / `↓` | 이전 / 다음 형제로 이동 |
| `Esc` | 선택 해제, 패널 닫기 |

입력창에 커서가 있거나 Ctrl/Alt/Cmd를 누른 상태에서는 동작하지 않습니다. 방향키로 이동하면 카메라도 해당 노드를 부드럽게 따라가요.

## 설정

툴바의 **설정**에서 인터페이스 언어와 이 레포의 브랜치 이름을 바꿀 수 있어요. **저장하고 다시 불러오기**를 누르면 둘 다 저장되면서 트리를 다시 읽어옵니다.

### 언어

뷰어와 VS Code 확장은 한국어와 영어를 지원해요.

| 선택 | 동작 |
|---|---|
| **자동** (기본값) | 브라우저 언어를 따릅니다. VS Code 확장에서는 VS Code 표시 언어를 따라 한국어면 한국어, 아니면 영어로 표시돼요 |
| **한국어** / **English** | 항상 선택한 언어로 표시됩니다 |

- 언어 설정은 레포와 상관없이 모든 레포에 공통으로 적용돼요.
- GitHub API는 사용자의 언어를 알려주지 않고, IP로 지역을 판단하려면 외부 서비스를 거쳐야 해요. 그래서 브라우저(또는 VS Code)에 설정된 언어를 기본값으로 씁니다.
- `researchtree` CLI는 시스템 언어(한국어 또는 영어)를 따릅니다. `RESEARCHTREE_LANG=en` 또는 `ko`로 정할 수 있습니다.

### 브랜치 설정

설정 창의 **브랜치 설정**(또는 "research 브랜치가 없습니다" 화면의 **브랜치 설정**)에서 이 레포의 브랜치 이름을 변경할 수 있어요.

| 항목 | 기본값 | 뜻 |
|---|---|---|
| 루트 브랜치 | `research` | 연구 트리의 루트로 쓸 브랜치 |
| 실험 브랜치 접두사 | `experiment/` | 이 접두사로 시작하는 head 브랜치의 PR만 노드가 됩니다 |

- 브랜치 이름을 입력하는 동안 아래에 예시(`research ← experiment/my-idea (PR base: research, 태그: research/v1, research/v2 …)`)가 미리 보여요.
- **저장하고 다시 불러오기**를 누르면 설정을 저장하고 트리를 다시 읽어요. 브랜치 이름을 원래대로 되돌리려면 **기본값**을 누르면 돼요.
- 설정은 **레포별로** 저장돼요. 웹과 로컬 실행은 그 브라우저에, VS Code는 확장 상태에 저장되니 팀원마다 각자 설정해야 해요.
- 자세한 입력 규칙은 [브랜치 설정 규칙](/rules/branches#브랜치-설정-규칙)을 참고해 주세요.

::: tip 학습 스크립트와 맞추기
브랜치 이름은 레포의 `.researchtree.yml`에서 읽어요. 뷰어에도, 학습 스크립트에도 따로 설정할 것이 없습니다([연구 기록 규칙](/rules/branches)).
:::
