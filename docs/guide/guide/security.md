# 보안과 개인정보

ResearchTree는 GitHub 토큰을 사용해 대상 레포의 PR 데이터를 읽고 써요. 토큰이 안전하게 보호되도록, 실행 환경(호스트)별로 토큰의 저장 위치와 통신 범위를 최소한으로 제한해 두었습니다.

## 저장하는 것과 저장하지 않는 것

- **GitHub가 유일한 저장소입니다.** ResearchTree는 별도의 데이터베이스나 서버 캐시를 일절 운영하지 않아요. 모든 실험 기록은 여러분의 레포(브랜치, PR, 태그) 안에 온전히 보관됩니다.
- 뷰어가 기기 로컬에 저장하는 데이터는 토큰(웹), 최근 본 레포, 마지막 레포, 보기 모드, 섬별 라벨 메트릭, 언어 설정, 레포별 브랜치 설정뿐이에요.

## 토큰 경계

토큰은 지정된 호스트 환경 경계를 절대 벗어나지 않아요. Webview 화면이나 로그, 그리고 `api.github.com` 외의 도메인으로는 전송되지 않습니다.

| 호스트 | 토큰 위치 | GitHub 호출 주체 |
|---|---|---|
| 중앙 웹 | 브라우저 `localStorage` | 브라우저 |
| VS Code 확장 | 확장 호스트(VS Code 인증 세션) | 확장 호스트. Webview는 메시지로 요청만 보냅니다 |
| 로컬 실행 | OS 키체인 또는 설정 파일(0600) | 로컬 Python 서버. 브라우저에는 토큰이 없습니다 |

- 모든 GitHub API 호출은 `api.github.com`의 상대 경로만 전달받아요. 전체 URL 요청은 거부하므로 어떤 환경에서도 토큰이 다른 도메인으로 새지 않습니다.
- 기본 요청 권한은 `repo` scope예요. 비공개 레포를 읽고 쓰려면 필요하지만, 접근할 수 있는 모든 비공개 레포에 쓰기 권한이 주어지는 다소 넓은 범위입니다. 권한을 최소화하고 싶다면 대상 레포만 지정한 **fine-grained PAT**(Pull requests 읽기/쓰기, Contents 읽기)를 사용하는 것을 추천해요.

## 중앙 웹

- **CSP**: 스크립트는 자체 출처(`'self'`)만 허용하고, 네트워크 연결 대상은 `api.github.com`과 인증 프록시로 한정해요. 이미지는 자체 출처와 GitHub 아바타만 허용합니다.
- 외부 CDN을 런타임에 호출하지 않아요. 글꼴(Pretendard, Fraunces, JetBrains Mono)까지 모두 번들에 포함되어 있습니다.
- **PR 본문 sanitize**: PR 본문은 신뢰할 수 없는 외부 입력값으로 다룹니다. 마크다운 렌더링 결과는 DOMPurify로 정제해 스크립트 실행을 방지하며, 본문 내 링크는 새 탭으로 열려요.
- **OAuth 흐름**: 로그인 시 난수 기반 `state`를 만들어 콜백 값과 검증하고, 인증을 마치자마자 주소창에서 `code` 파라미터를 즉시 지웁니다.

### 인증 프록시

GitHub 토큰 교환 엔드포인트는 CORS를 지원하지 않아 브라우저에서 직접 호출할 수 없어요. 이를 중계하기 위해 가벼운 Cloudflare Worker(`https://researchtree.thisisthepy.workers.dev`)를 둡니다.

- 프록시가 하는 일은 **OAuth code를 토큰으로 교환하는 것 하나**뿐이에요 (`POST /token`).
- 토큰이나 요청 본문을 서버에 저장하거나 로그로 남기지 않습니다.
- 허용된 Origin(공식 사이트, 개발용 `http://localhost:5173`)에서 온 요청만 받아요.
- client secret은 Worker secret으로만 안전하게 보관합니다.

PAT로 로그인하면 인증 프록시를 전혀 거치지 않고 GitHub로 바로 통신해요.

::: warning 준비 중
인증 프록시와 OAuth App은 아직 배포되지 않았습니다.
:::

## VS Code 확장

- Webview는 확장 폴더 안의 빌드 파일만 읽을 수 있고, nonce 기반 CSP가 적용되어 있습니다.
- Webview는 토큰을 알지 못해요. GitHub 요청은 내부 메시지로 확장 호스트에 전달되고, 확장 호스트가 동일한 경로 검증을 거쳐 호출합니다.

## 로컬 실행

- `127.0.0.1`에만 바인딩됩니다.
- DNS rebinding 공격을 막기 위해 `Host` 헤더가 `127.0.0.1:<포트>`나 `localhost:<포트>`가 아니면 정적 파일을 포함한 모든 요청을 거부해요.
- 실행할 때마다 새 세션 토큰을 만들어 서빙하는 HTML에 주입하고, 모든 `/api/*` 요청에 이 토큰을 요구합니다. 다른 사이트의 페이지가 로컬 API를 부를 수 없어요.
- GitHub 중계(`/api/github/*`)는 GET, POST, PATCH, PUT만 허용하며, DELETE 요청은 차단합니다.

## 학습 스크립트

`rt.log()` 등은 로컬에 저장된 토큰(또는 `RESEARCHTREE_TOKEN`)으로 현재 브랜치의 PR 본문만 안전하게 수정해요. 여러 사람이 함께 쓰는 공용 서버에서 `RESEARCHTREE_TOKEN`을 쓸 때는 셸 기록이나 공유 스크립트에 토큰 문자열이 남지 않도록 주의해 주세요.
