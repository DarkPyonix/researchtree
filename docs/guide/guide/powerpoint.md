# PowerPoint 확장

슬라이드 위에 연구의 섬을 그대로 올릴 수 있어요. 발표 중에도 살아 있어서, 드래그해서 돌리고 실험을 눌러 열 수 있습니다. 캡처 이미지가 아니라 진짜 뷰어예요.

::: info 준비 중
애드인은 만들어져 있고 사이드로드로 바로 쓸 수 있어요. Microsoft AppSource 등록은 심사 절차가 남아 있습니다.
:::

## 지금 설치하기

스토어 등록 전에도 매니페스트 파일 하나면 설치할 수 있고, 기능 제한은 없어요. 파일은 저장소의 [`apps/office/manifest.xml`](https://github.com/DarkPyonix/researchtree/blob/main/apps/office/manifest.xml)에 있습니다.

- **웹 PowerPoint**: 삽입 → 추가 기능 → **내 추가 기능 업로드**에서 `manifest.xml`을 고르세요.
- **Windows**: `manifest.xml`을 공유 폴더에 두고, 파일 → 옵션 → 보안 센터 → 보안 센터 설정 → 신뢰할 수 있는 추가 기능 카탈로그에 그 폴더를 등록한 뒤 **메뉴에 표시**를 켜요. PowerPoint를 다시 켜면 삽입 → 내 추가 기능에 보입니다.
- **Mac**: `manifest.xml`을 `~/Library/Containers/com.microsoft.Powerpoint/Data/Documents/wef`에 복사한 뒤 삽입 → 내 추가 기능을 여세요.

## 발표할 때 알아둘 것

- **로그인 없이 보여줄 수 있어요.** 공개 레포라면 주소에 레포를 적어 두는 것만으로 바로 뜹니다. 발표 중에 로그인 창을 띄울 일이 없어요. 자세한 건 [중앙 웹](/guide/web)의 공유 링크를 참고하세요.
- **슬라이드쇼를 시작할 때마다 화면이 새로 뜹니다.** 보여주고 싶은 실험이 있다면 주소에 노드까지 적어 두세요.
- **인터넷이 필요해요.** GitHub에서 실험 기록을 읽어오기 때문입니다.
- **로그인도 됩니다.** 비공개 레포를 보여주려면 애드인 안에서 GitHub 로그인 창이 열려요. 다만 애드인은 토큰을 저장하지 않기 때문에, 발표 파일을 다시 열면 다시 로그인해야 해요.

## 잘 안 될 때

- **3D가 느리면** 평면 보기나 칸반 보기로 바꿔 보세요. 발표용 PC의 그래픽 설정에 따라 3D가 느려질 수 있어요.
- **빈 화면이면** 네트워크와 레포 주소를 확인해 주세요.
- 발표 전에 실제 발표할 PC에서 한 번 띄워 보는 것을 권합니다.
