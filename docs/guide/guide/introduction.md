# 소개

*Every branch is an experiment. Every PR is its lab note.*

ResearchTree는 Git 브랜치와 Pull Request를 바탕으로, 연구 과정을 초기 구현에서 점점 자라나는 실험 트리로 시각화해 주는 도구예요.

![3D 연구의 섬](/images/readme/ko/island.png)

## 왜 필요한가

연구를 하다 보면 기준 코드를 조금씩 바꿔 보는 실험이 수없이 생깁니다. 하지만 실험 기록은 보통 W&B 대시보드나 개인 노트, 메신저, 커밋 메시지 곳곳에 흩어지기 일쑤죠. 시간이 지나면 어떤 아이디어가 어디서 파생됐고, 무엇이 채택되고 왜 기각됐는지 한눈에 파악하기 어렵습니다.

ResearchTree는 단순한 규칙 네 가지로 이 문제를 풀어냅니다.

| 규칙 | 의미 |
|---|---|
| **브랜치 하나 = 실험 하나** | 브랜치에는 가설 하나를 검증하는 작고 명확한 코드 수정만 담아요 |
| **PR 하나 = 실험 일지 하나** | PR 본문에 가설, 변경점, 메트릭, 결론을 빠짐없이 기록합니다 |
| **분기 관계 = 트리** | 실험 B를 실험 A에서 갈라내면 트리에서도 자연스럽게 A의 자식이 돼요 |
| **PR 상태 = 실험 결론** | open은 진행 중, merged는 채택, closed는 기각을 뜻해요 |

뷰어는 이 PR들을 모아 트리로 그려줍니다. 노드를 클릭하면 가설과 결론, 메트릭, 커밋 내역을 바로 확인할 수 있어요. 모든 데이터는 GitHub에 그대로 저장되며, 별도의 데이터베이스나 서버 캐시도 두지 않습니다.

```
research (v1)                  ← 트리의 루트 (초기 구현)
├─ experiment/baseline-moshi
│  ├─ experiment/depth-lr-half      (기각)
│  └─ experiment/depth-lr-warmup    (채택 → research v2)
│                                   └─ research v2 에서 다시 뻗는 실험들 …
└─ experiment/...

main, develop, 기타             ← 연구 외 용도. 트리에 표시하지 않음
```

## 오픈 사이언스

모든 실험 기록이 레포 안에 고스란히 남습니다. 시도할 때마다 코드와 가설, 메트릭, 채택·기각 사유가 평범한 브랜치와 PR로 차곡차곡 쌓여요. 비공개 노트나 별도 데이터베이스에 파묻히는 기록이 없습니다.

덕분에 레포만 공개해도 최종 결과뿐 아니라 그 과정 전체를 투명하게 나눌 수 있어요. 논문에서 흔히 빠지기 쉬운 실패한 실험이나 스쳐 지나간 아이디어까지 모두 포함되죠. 누구든 관심 있는 브랜치를 체크아웃해 실험을 직접 재현해 보거나, 부모 실험과 비교하고, 곧바로 후속 연구로 이어갈 수도 있습니다. ResearchTree는 연구 과정을 온전히 드러내 투명하고 재현 가능한 오픈 사이언스를 돕습니다.

## 세 가지 사용 방법

환경에 맞춰 세 가지 방법으로 뷰어를 열 수 있어요. 어떤 방식을 고르든 처음에 GitHub 로그인 한 번만 거치면 됩니다.

| 방법 | 특징 | 안내 |
|---|---|---|
| **중앙 웹** | 별도 설치 없이 링크 하나로 화면 공유 | [중앙 웹](/guide/web) |
| **VS Code 확장** | 워크스페이스 레포 자동 인식, 브랜치 체크아웃과 diff 지원 | [VS Code 확장](/guide/vscode) |
| **로컬 실행** | `researchtree serve` 명령어로 중앙 서버 없이 셀프 호스팅 | [로컬 실행](/guide/local) |

학습 스크립트 안에서는 Python 패키지를 활용해 `rt.log(val_loss=...)`처럼 PR에 메트릭을 손쉽게 남길 수 있어요 ([학습 스크립트 연동](/guide/tracking)).

## 현재 상태

::: warning 아직 없는 것
- **Open VSX**: VS Code 확장은 VS Code Marketplace에만 올라가 있어요. Open VSX 등록은 곧 할 예정이에요.
- 새 실험 생성, 타임라인 재생, 투어 모드, 검색, 미니맵은 아직 지원하지 않아요. 새 실험은 GitHub에서 브랜치와 PR을 만들어 시작해 주세요.
:::
